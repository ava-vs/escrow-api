# Тестирование Escrow API

## Общая информация

В проекте используется фреймворк Jest для модульного и интеграционного тестирования. Тесты расположены в директории `/__tests__` и организованы в соответствии со структурой проекта.

## Структура тестов

Тесты разделены на две основные категории:

1. **Модульные тесты** - тестируют функциональность отдельных компонентов (сервисов):
   - `/__tests__/lib/escrow-lib/services/` - тесты для отдельных сервисов
   - `/__tests__/lib/escrow-lib/escrow-manager.test.ts` - тесты для основного класса EscrowManager

2. **Интеграционные тесты** - тестируют взаимодействие между компонентами:
   - `/__tests__/lib/escrow-lib/integration/` - комплексные сценарии использования системы

## Модульные тесты

### EscrowManager Tests

Файл: `/__tests__/lib/escrow-lib/escrow-manager.test.ts`

Тесты проверяют основную бизнес-логику и взаимодействие между сервисами:

- **User Management**:
  - Создание нового пользователя
  - Получение информации о пользователе по ID
  - Обновление баланса пользователя

- **Order Management**:
  - Создание нового заказа с этапами (milestones)
  - Создание группового заказа
  - Назначение исполнителя
  - Внесение средств в заказ

- **Document Management**:
  - Создание документов различных типов
  - Просмотр документов заказа
  - Утверждение документов

### UserService Tests

Файл: `/__tests__/lib/escrow-lib/services/user-service.test.ts`

Тесты проверяют функциональность сервиса для управления пользователями:

- Создание пользователя различных типов (CUSTOMER, CONTRACTOR, PLATFORM)
- Получение пользователя по ID
- Проверка наличия достаточного баланса
- Обновление баланса пользователя
- Проверка типа пользователя (isCustomer, isContractor)

### OrderService Tests

Файл: `/__tests__/lib/escrow-lib/services/order-service.test.ts`

Тесты проверяют функциональность сервиса для управления заказами:

- Создание заказа с этапами
- Создание группового заказа
- Получение заказа по ID
- Назначение исполнителя
- Получение и обновление этапов заказа
- Внесение средств в заказ
- Голосование за представителя в групповом заказе

### DocumentService Tests

Файл: `/__tests__/lib/escrow-lib/services/document-service.test.ts`

Тесты проверяют функциональность сервиса для управления документами:

- Создание документов различных типов (техническое задание, дорожная карта, отчет)
- Получение документа по ID
- Утверждение документа пользователями
- Создание акта выполненных работ
- Подписание акта выполненных работ

## Интеграционные тесты

### Выполнение заказа (Order Completion Flow)

Файл: `/__tests__/lib/escrow-lib/integration/order-completion.test.ts`

Тестирует полный жизненный цикл заказа от создания до завершения:

1. Создание пользователей (заказчик и исполнитель)
2. Создание заказа с этапами
3. Финансирование заказа заказчиком
4. Назначение исполнителя на заказ
5. Выполнение работы исполнителем и создание результата
6. Создание акта выполненных работ
7. Подписание акта заказчиком
8. Завершение этапа и выплата исполнителю

### Управление групповыми заказами (Group Order Management)

Файл: `/__tests__/lib/escrow-lib/integration/group-orders.test.ts`

Тестирует функциональность групповых заказов:

1. Создание группового заказа с указанием представителя
2. Голосование заказчиков за нового представителя
3. Смена представителя при достижении большинства голосов
4. Отслеживание взносов от нескольких заказчиков

### Работа с документами (Document Workflow)

Файл: `/__tests__/lib/escrow-lib/integration/document-workflow.test.ts`

Тестирует процессы работы с документами:

1. Создание и утверждение дорожной карты проекта
2. Создание и утверждение технического задания
3. Создание и обновление критериев приемки (definition of done)
4. Утверждение документов несколькими сторонами

## Запуск тестов

Для запуска всех тестов выполните:

```bash
npm test
```

Для запуска конкретного теста:

```bash
npm test -- -t "название теста"
```

## Мокирование зависимостей

В тестах используется мокирование внешних зависимостей, таких как база данных и внешние сервисы, с помощью Jest.

Пример мокирования базы данных:

```typescript
jest.mock('../../lib/db', () => ({
  insert: jest.fn().mockResolvedValue(/* mock data */),
  select: jest.fn().mockResolvedValue(/* mock data */),
  update: jest.fn().mockResolvedValue(/* mock data */),
  transaction: jest.fn().mockImplementation(async (callback) => await callback({ /* mock transaction object */ }))
}));
```
