## Анализ проектов

### escrow-api-1 (Next.js)
- Проект построен на Next.js 15.1.3
- Использует Drizzle ORM с Neon Database (PostgreSQL)
- Имеет минимальную API-структуру (только auth и seed)
- Успешно развернут на Vercel

### escrow-docker (NestJS)
- Построен на NestJS
- Имеет обширный функционал для работы с эскроу-системой
- Включает работу с групповыми заказами, платежами и другими функциями
- Содержит сервисы для работы с документами, пользователями, заказами и т.д.
